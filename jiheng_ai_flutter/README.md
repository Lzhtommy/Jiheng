# Jiheng AI Flutter Prototype

This Flutter project recreates screens 1 to 4 from `JihengAI-v3.dc.html`.

Run the Flutter setup commands yourself from this folder. For example, you can generate any missing platform folders with Flutter tooling, then run the app normally.

The implemented screens are:

- 01 Home
- 02 Chat Q&A
- 03 Agent execution
- 04 Generated report
