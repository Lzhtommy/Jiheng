# 玑衡 AI：专业投研与产业链探索的双主线设计

> 本文记录当前讨论结论，作为黑客松产品方向的工作草案；并非最终功能规格。

## 一句话定位

玑衡 AI 不是单纯的 AI 选股工具，也不是让用户扮演真实公司 CEO 的经营模拟器。

它是一套共用“公司研究与证据链”底层的双主线产品：一端服务专业研究，另一端让金融小白以游戏化方式探索公司与产业链。

## 两条主线

| 主线 | 暂定名称 | 面向用户 | 产品形态 | 用户获得的价值 |
| --- | --- | --- | --- | --- |
| 专业主线 | 玑衡 Research | 独立研究员、资深投资者、分析师 | 可溯源金融分析 Agent / 研究工作台 | 更快研究、核验证据、发现反例与风险 |
| 探索主线 | 玑衡 World | 金融小白、学生、对公司经营感兴趣的用户 | 公司与产业链探索游戏 | 看懂公司如何赚钱、受谁影响、风险从哪里来 |

两条主线不应被当成两个独立产品，而是同一套研究引擎的两种表达。

```text
公司 / 财报 / 公告 / 行业 / 产业链关系 / 历史事件 / 证据链
                              ↓
             多 Agent 研究与验证引擎
                     ↙                    ↘
      玑衡 Research（专业工作台）   玑衡 World（探索小游戏）
```

## 专业主线：玑衡 Research

### 不直接与大而全终端竞争

市面上已经有专业金融终端、金融分析套件与 AI 投研产品。玑衡 Research 不应以“数据最全”或“功能最多”为主要卖点，而应聚焦以下差异：

- **每个结论可回溯**：数字、财报字段、公告内容和推断都能看到来源、日期与原始证据；
- **每个观点可反驳**：Bull / Bear Agent 基于同一证据集提出支持与反例；
- **硬数据与 AI 推断分开**：情绪、标签、归因等衍生内容必须显示“AI 推断”和置信度；
- **研究过程可复盘**：支持按历史时间点截断数据，避免事后视角和 lookahead bias；
- **只做研究辅助**：不输出买卖时机、目标价或明确荐股结论。

### 核心工作流

```text
问题 / 公司
  → Agent 拆解研究任务
  → 数据与公告取证
  → 公司诊断与产业链关系
  → 多空辩论与压力测试
  → 证据链、待验证假设、风险清单
```

## 探索主线：玑衡 World

### 核心体验

玑衡 World 不是“模拟 CEO”。玩家不直接替真实上市公司决定扩产、降价或融资；这种设定容易偏离投研，也会让真实公司分析变成脱离数据的经营游戏。

玩家更适合扮演：

> **产业链探索者 / 投研学徒**

用户进入一家公司的“产业链世界”，跟着一组有明确职责的研究员 Agent，逐步理解该公司靠什么赚钱、上下游是谁、重大事件如何传导、哪些假设最脆弱。

### 从 OC World 借鉴什么

借鉴的重点不是虚拟角色或像素风，而是 OC World 的体验结构：

- **Agent 有自主性**：研究员会主动发现公告、事件和矛盾点，而不只是被动回答问题；
- **世界会生长**：产业链节点、关系和事件会随着探索不断解锁；
- **用户是观察者兼参与者**：用户选择调查方向、追问或质疑，而不是填写一张枯燥表格；
- **角色之间有张力**：不同 Agent 的职责、立场和证据不同，形成可观看的讨论。

### 一次探索的游戏循环

```text
选择一家公司
  → 打开公司档案
  → 进入产业链地图
  → 领取一个调查问题 / 事件任务
  → 与研究员 Agent 对话、收集证据
  → 解锁上下游节点与风险事件
  → 形成“我目前理解的公司”卡片
  → 可一键跳转到专业研究页查看完整证据
```

### Agent 角色建议

| Agent | 负责的问题 | 对玩家的价值 |
| --- | --- | --- |
| 公司档案员 | 公司做什么、主要业务、关键财务指标 | 先建立基础认知 |
| 财报侦探 | 营收、利润、现金流、资产负债表变化 | 把财报翻译成能理解的故事 |
| 上游观察员 | 原材料、供应商、成本变化 | 解释成本压力从哪里来 |
| 下游观察员 | 客户、需求、竞争与替代品 | 解释收入和市场空间 |
| 事件记者 | 公告、政策、行业新闻和时间线 | 让变化变得可追踪 |
| 风险猎人 | 反例、未验证假设、关键风险 | 防止游戏只讲“好消息” |
| 证据官 | 来源、日期、原始字段、AI 推断标识 | 保证每个叙事可核验 |

## 两条主线如何互通

| 探索小游戏中的动作 | 专业研究中的对应能力 |
| --- | --- |
| 点击产业链节点 | 查看公司、行业或事件的底层数据与来源 |
| 解锁一条“线索” | 新增一条带来源的研究证据 |
| 与风险猎人对话 | 触发 Bear Case / 压力测试 |
| 形成玩家理解卡 | 生成可导出的研究假设和待验证清单 |
| 进入“深度模式” | 跳转到 玑衡 Research 的完整诊断页 |

探索模式不是低质量的“阉割版投研”，而是把同一套可靠研究结果翻译成更直观、更有参与感的体验。

## 黑客松第一版建议

### 只做一个完整公司世界

第一版不做全市场，不做多个行业。选择一家产业链清晰、上下游故事足够丰富的公司即可。宁德时代是一个适合作为演示样本的候选：

```text
锂矿 / 镍钴等原材料
  → 正极、负极、电解液、隔膜
  → 动力电池
  → 车企、储能系统
  → 消费者、政策、海外市场
```

### P0：必须跑通的体验

1. 公司档案页：公司业务、核心数字与来源；
2. 产业链地图：至少 5 个节点和可点击的传导关系；
3. 三位可对话/可行动的研究员 Agent：档案员、产业链观察员、风险猎人；
4. 一条事件任务：例如“原材料价格上升会如何影响电池公司”；
5. 每条事实可打开来源；AI 推断明确带标识；
6. 一键进入专业模式，展示多空论证与证据链。

### P1：现场更有记忆点的功能

- 时间机器：回到历史日期，只展示当时可得的信息，再揭晓后续事实；
- “只看硬数据”开关：隐藏所有 AI 推断；
- “做空我的观点”：玩家输入理解，风险 Agent 逐条找反例；
- 产业链冲击波：输入一个事件，观察影响沿产业链扩散。

### 暂不做

- 实盘交易、持仓导入、买卖建议、目标价；
- 全市场实时行情和 Level-2 数据；
- 复杂的真实公司经营决策模拟；
- 为了“像游戏”而脱离真实数据和证据链的数值系统。

## 合规与可信度底线

- 全局声明：产品是研究与教育辅助，不构成投资建议；
- 不输出“买、卖、目标价、何时买卖”等指令；
- 所有硬数据保留来源、口径与时间；
- AI 生成的标签、归因、关系和叙事必须显著标注为衍生内容；
- 现场演示优先使用提前缓存的公开历史数据，避免实时接口不稳定；
- 游戏叙事可以有角色感，但不得把未经验证的故事包装成事实。

## 当前讨论结论

玑衡的专业主线负责 **可信与深度**；探索主线负责 **可玩、可懂与可传播**。

两者应建立在同一套公司研究、产业链关系和证据链之上。这样既避免在专业终端赛道硬拼数据广度，也避免小游戏沦为与金融无关的“CEO 模拟器”。
