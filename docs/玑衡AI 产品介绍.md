# 玑衡AI 产品介绍

> 上古先民以玑衡观测星辰、校准时序；玑衡AI 以 Agent 观测财报、因子与市场信号，自动丈量市场规律，预判资产周期。

**Slogan：璇玑为机，玑衡为器**

---

## 1. 一句话介绍

**玑衡AI 是一款对话式 A 股投研 Agent 应用：接入全 A 股行情、公告年报 PDF 与财务数据，用多 Agent 编排做出逐条可溯源的公司/行业深度诊断和研报，并用一款情景模拟游戏「玑衡World」让新手也能看懂。**

三种模式（快速问答 / 深度研究 / 分析师）覆盖从随手一问到机构级研报的全部投研场景。产品定位为**研究辅助与投资教育工具，不提供个股买卖建议**。

## 2. 我们要解决的问题

个人投资者与买方研究员的投研工作长期被三个矛盾撕扯：

| 矛盾 | 具体表现 |
| --- | --- |
| **广度 vs 深度** | 通用大模型（DeepSeek/豆包/文心/千问）已能"聊金融"，但无实时数据接入、易幻觉（DeepSeek-R1 幻觉率 14.3%），给出"正确的废话" |
| **专业 vs 门槛** | Wind Alice、Choice 等机构级工具数据权威、结论可直接交付，但价格高、界面重，专业级个人被"夹在中间" |
| **可信 vs 可用** | 东财妙想、i问财等已做信源分级，但溯源停留在"文章级"，散户仍无法逐条核实一个数字到底来自哪张报表、哪份公告 |

玑衡AI 的答案不是复刻数据广度，而是在**证据链彻底性、专业投研深度、认知门槛**这三个所有竞品都做得不彻底的地方做深。

## 3. 目标用户

| 角色 | 核心诉求 | 玑衡AI 对应能力 |
| --- | --- | --- |
| 买方 / 卖方研究员 | 快速梳理事件驱动、生成研报草稿、跟踪产业链 | 专业投研 Agent、公告全文检索、可溯源诊断 |
| 投资顾问 / 理财师 | 客户问题快答、晨会纪要、产品解读 | 快速问答模式、分析师、晨报 |
| 组合管理者 / 交易员 | 周度归因、盘中异动归因 | 深度研究模式、定时任务与提醒 |
| 专业级个人投资者 | 可复现的研究流程、别被忽悠 | 数据出处逐条可查、多空证据并陈 |
| 零基础 / 新手投资者 | 看得懂、有陪伴感、不害怕专业名词 | **玑衡World** 情景模拟游戏 |

## 4. 核心能力全景

- **三种对话模式**：快速问答 / 深度研究 / 分析师（个股 / 行业 / 财报 3 类分析师角色）；「分析师」模式下可选开启「多 Agent 协作」，实时展示任务拆解、分工执行、交叉审核、逐层汇总的协作图谱与时间线
- **技能广场**：36 个官方技能 + 用户自建技能，把机构沉淀的分析框架（板块透视、期权波动率诊断等）封装为可复用能力
- **报告库**：深度研究 / 公司研究 / 晨报等归档、查看与导出
- **对话历史与收藏**：历史会话侧边栏随时回看，答案要点一键收藏
- **自动化**：定时任务（cron）已支持创建与管理；条件触发提醒仍在完善中
- **合规底线**：所有输出经服务端强制校验——风险提示、引用溯源、禁用词过滤、「内容由 AI 生成，请核查重要信息」声明；不输出买卖时机、目标价、明确荐股

这些是玑衡AI 的"骨架"；真正让它区别于市面上所有对话式金融 AI 产品的，是下面四个独有能力。

## 5. 独有优势

### 5.1 独家全 A 股公告/财报数据全文检索

在传统量价数据、基本面数据之外，玑衡AI 独有地接入**全 A 股公告与定期财报数据**（沪深北三大交易所全文检索），支持按股票代码、关键词、时间区间定位到具体一份公告、一条披露——不是标题+摘要级的检索，而是数字级、可直接核验原文的信息源。

- **对比同花顺 i问财 / 东财妙想**：两者的公告解读停留在标题+摘要级，玑衡AI 做到全文检索、数字级溯源。
- **解决的痛点**：社区反馈通用大模型常"用过时数据计算""个股代码与名称不匹配"——公告全文检索与逐条溯源从源头上杜绝了这类数据陷阱。

### 5.2 专业投研 Agent：多 Agent 编排穿透全产业链

面向公司/行业的专业投研需求，玑衡AI 不是单一 Agent 单轮问答，而是通过**多 Agent 编排**（规划 → 分工取数 → 交叉验证 → 汇总裁决）深入调研一家公司或一个行业的全产业链数据——上游供应商、下游客户、同业对标、政策与宏观联动一并纳入分析范围，最终产出专业级投研报告。

- **对比 Wind Alice「报告神笔」/ 东财"AI 研究员一键生成行业研报"**：这些是模板化生成，玑衡AI 是任务分解式的多 Agent 协作，更接近真实研究员的工作方式，而非套模板填空。
- **对比蚂蚁"金融图谱"（200 万+实体、1100 万+关系）**：蚂蚁的图谱服务于理财陪伴场景，不做个股/行业深度研究；玑衡AI 把产业链穿透用在真正的投研产出上。
- **不是停留在后台的"黑箱协作"**：这套编排在客户端呈现为可视化的「协作图谱」——首席分析师拆出的子任务节点、每个节点的派发/提交/打回/通过状态、研究→审核→撰写三阶段的实时进度，用户可以像看任务看板一样看到一份研报是如何被"分工"出来的。

### 5.3 可溯源公司/行业诊断：结论到出处，逐条可核验

玑衡AI 拉取财务、行情、公告数据后，由 LLM 生成结构化诊断，但**每一条结论都必须挂载数据出处**——精确到接口名 + 原文链接，而不是"参考了 N 篇资料"这种文章级的模糊溯源。

- **这是竞品分析报告中反复强调的"所有竞品都做得不彻底"的能力**：东财妙想有信源分级、华泰 AI 涨乐有"推理可视化"、海外 Fiscal.ai 强调"不编造数字"，但没有一家做到字段级、接口级的逐条可核验。
- **直接回应行业最大痛点——信任**：DeepSeek-R1 幻觉率 14.3%，联网信息易被"股市黑嘴/小作文"污染；玑衡AI 用"无出处不下结论"的产品级设计正面对抗幻觉。
- **不是软性的提示词约束，而是代码层强制校验**：服务端有一条专门的校验链，逐条检查风险提示是否存在、引用列表是否为空、含百分比等数字的结论是否挂了来源、是否出现"买入/卖出/满仓/空仓"等禁用词——任意一项不通过都会被打回重写，而不是靠模型"自觉"。
- **同时是天然的合规护栏**：呈现证据与逻辑而非给出买卖结论，规避《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》红线，是"安全区"里最彻底的实现。

### 5.4 玑衡World：游戏化的投研启蒙

玑衡AI 独有「玑衡World」情景模拟游戏——App 首页顶部以「玑衡AI / 玑衡World」双 Tab 呈现，切换时有渐进式过场动画，游戏本体是内置打包的离线 HTML5 小游戏（无需联网加载外部页面）。目前已上线首个旗舰场景「采购之旅」：用户以**第一视角走进新能源电池产业链**，从盐湖提锂矿场出发，途经材料车间、电芯车间，直至下游港口交付，沿途与 NPC 谈条件、收集卷轴，逐步积累对这条产业链成本结构、上下游关系与议价能力的认知。地图式的多场景串联框架已经落地，后续会持续以同样机制扩展到更多行业与场景（上下游、同业、行业周期），把原本枯燥的产业链调研变成可探索、有反馈的过程。

- **这是当前所有竞品报告中都未出现的品类**：Fey 靠极简设计降门槛、雪球思考靠可视化图谱降门槛，但没有一家用"游戏"来降门槛。
- **精准填补竞品分析报告指出的用户鸿沟**：散户要"陪伴式、看得懂的结论"，专业用户要"可溯源证据链"——玑衡World 让同一套产业链数据同时服务两种心智，新手玩着玩着就懂了行业逻辑，再自然过渡到专业模式下的深度诊断与投研报告。
- **也是留存与获客的天然抓手**：游戏化机制天然具备传播性和粘性，不依赖"荐股"这类合规敏感的增长手段。

## 6. 与主要竞品的差异化定位

| 维度 | Wind Alice | 同花顺 i问财 | 东财妙想 | 玑衡AI |
| --- | --- | --- | --- | --- |
| 目标人群 | 机构/专业理财师，价格预计偏高 | 散户为主，通用选股 | 散户为主，免费触达 | 专业级个人为主，简化模式兼容散户 |
| 公告/年报解析深度 | 强（文档智读） | 中（标题摘要） | 强（信源分级，仍偏摘要） | **数字级 + 公告全文检索** |
| 研究产出方式 | 模板化生成（报告神笔） | 单轮问答为主 | 模板化生成（AI 研究员） | **多 Agent 编排 + 全产业链穿透** |
| 溯源颗粒度 | 强（但文章级为主） | 中 | 强（信源分级，仍非字段级） | **字段级：接口名 + 原文链接，逐条可核验** |
| 新手教育/降门槛方式 | 无 | 无 | 无 | **玑衡World 情景模拟游戏** |
| 合规姿态 | 机构工作台，边界清晰 | 曾有"给具体标的"合规争议 | 边界较清晰 | 全程呈现逻辑与证据，不下结论 |

结论：玑衡AI 不与巨头拼数据广度和交易执行闭环，而是在**证据链彻底性、专业研究深度、认知门槛**三个所有竞品都留有空隙的维度上建立护城河。

## 7. 信任与合规设计

- 定位为「研究辅助与投资教育工具」，不提供个股买卖建议、不做目标价预测。
- 所有 AI 输出强制附带风险提示与「内容由 AI 生成，请核查重要信息」声明。
- 数值类结论（涨跌幅、分位、同比等）必须在引用列表中至少对应一条可追溯来源；无出处不输出。
- 多空证据并陈、呈现推理逻辑而非直接结论，从产品设计层面规避"荐股软件"监管红线。

## 8. 产品愿景

「璇玑为机，玑衡为器」——玑衡AI 希望从一个输入框开始，用可信的数据底座、专业的多 Agent 投研能力，以及一款能让任何人都愿意打开的游戏，把机构级的研究深度和普通人能理解的语言之间的鸿沟填平。

## 9. 名词速查

| 名词 | 解释 |
| --- | --- |
| 分析师 | 「分析师」模式下可选择的角色，当前上线个股 / 行业 / 财报三类，各自对应一套专门的研究方法论 |
| 多 Agent 协作 / 协作图谱 | 「分析师」模式的可选增强：把一次研究任务拆解成任务树，由多个 Agent 节点分工取数、交叉审核、逐层汇总，客户端以图谱与时间线实时呈现执行过程 |
| 技能广场 | 把机构沉淀的分析框架封装成的可复用能力卡片，分"官方技能"与用户"自建技能"，可按需开关 |
| 溯源 / 引用 | 每条数值类结论必须挂载的数据出处（接口 + 原文链接），无出处的结论会被拦截、不予展示 |
| 玑衡World | 内置的离线情景模拟小游戏，用第一视角探索产业链，当前旗舰场景为新能源电池产业链「采购之旅」 |
| 定时任务 / 提醒 | 定时任务为已实现的 cron 周期任务；「提醒」目前是产品规划中的条件触发能力，尚在完善中 |
